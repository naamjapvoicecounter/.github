## Overview

Naam Jap Voice Counter is an open-source, web-first platform designed to assist spiritual practitioners with sacred chanting (*Naam Smaran & Japa Sadhana*). It removes the common physical friction of manual bead counters and mobile screen taps by leveraging in-browser speech processing, discreet stealth interfaces, and automated voice notifications.

### Core Architectural Features

- **Voice Recognition Engine**: Integrated speech recognition models detect sacred chanting in real time, automatically incrementing counts without manual device input.
- **Stealth Interface (Secret Mode)**: Ultra-minimalist, blacked-out AMOLED display designed for discreet chanting in workplace environments, transit, and public spaces.
- **Automotive Hands-Free Mode**: Spoken milestone alerts delivered via Bluetooth or vehicle audio systems, enabling safe counting during commutes.
- **Zen Contemplation Mode (Dhyan Mode)**: Reduced cognitive load interface featuring ambient breathing rhythms and full hardware keyboard support.
- **Adaptive Thematic System**: Contextual aesthetic styling dynamically customized for different traditions (Vrindavan, Ayodhya, Kashi, Kailash).
- **Persistent Local Data Store**: All counts are committed synchronously to browser IndexedDB / LocalStorage, guaranteeing zero data loss across browser sessions.
- **Encrypted Data Portability**: Client-side JSON and CSV serialization for complete data migration between personal devices.
- **Vedic Scriptural Repositories**: Curated collections of verified Sanskrit mantras accompanied by transliterations, meanings, and phonetic pronunciation guides.

## Guiding Principles & Data Sovereignty

> *"नाम संकीर्तनं यस्य सर्वपाप प्रणाशनम्।*  
> *प्रणामो दुःखशमनस्तं नमामि हरिं परम्॥"*

1. **Unconstrained Practice**: Sadhana is individual and unbounded. The platform places no artificial quotas or session caps on your chanting.
2. **Zero Distraction**: The chanting screen remains strictly unencumbered by disruptive popups or advertisements.
3. **Absolute Privacy**: All voice data is processed ephemeral in memory; no chanting audio or counts are ever transmitted to external cloud servers.
